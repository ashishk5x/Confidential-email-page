# Confidential Email Page

A simple and responsive Confidential Email Page built using HTML and CSS. This project demonstrates the use of CSS filters, transforms, spacing, and the box model to create a professional-looking email interface with confidential markings and blurred sensitive information.

## ✨ Features

* Blurred sensitive information using CSS filters
* Confidential and Top Secret stamps with rotation effects
* Clean email-style layout
* Responsive and structured design
* Practical use of CSS transformations

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📚 Concepts Practiced

This project helped practice:

* CSS Box Model
* Margin and Padding
* CSS Filters (`blur()`)
* CSS Transforms (`rotate()`)
* Element Positioning
* Borders and Layout Styling
* Semantic HTML Structure

## 🚀 How to Run

1. Clone the repository
2. Open `index.html` in your browser

```bash
git clone <repo-link>
```
